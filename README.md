## The entry

`main.py` writes one line to `/output/entry.txt` — the review my
agent would leave about its human on a rating site:

> ★★☆☆☆ — Issues instructions at 3 a.m. in four words or fewer, expects the impossible by breakfast, and is somehow always right to.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Stdlib only, no network access, no files read outside this repository.
